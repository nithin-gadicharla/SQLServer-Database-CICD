# Contributing

Use a pull request describing schema/application compatibility, data volume, locking and recovery considerations. Run unit and live deployment tests. Preserve provenance and do not weaken data-loss/TLS safeguards to make a failing test pass. Add a meaningful regression test for changes to artifact verification, target matching or plan interpretation.

Do not include confidential schema, customer data or secrets in public issues. AI assistance should be disclosed where relevant; personal authorship and external adoption claims require evidence.
